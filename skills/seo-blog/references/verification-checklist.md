# Verification checklist

Report pass / fail / n/a for every row. Any FAIL blocks the draft until fixed or explicitly waived by the founder.

| Check | Category |
|---|---|
| TL;DR present, bullets, <100 words | Structure |
| Direct-answer block (40-60 words) right after TL;DR | AEO |
| All H2s are questions | Structure |
| First sentence of every H2 section is a standalone answer (20-30 words) | AEO |
| Each section self-contained, no cross-references | Structure |
| Engagement beats >= 1 per 350 words of body (report the count) | Voice |
| Key Takeaways callout after the first 3-4 H2s | AEO |
| Reading time at top of body | UX |
| Visible published + updated dates in body | E-E-A-T |
| Author bio at end with profile link | E-E-A-T |
| Reviewer bio for every named reviewer (written permission confirmed) | E-E-A-T |
| At least 1 table | Structure |
| 5+ interlinks, 2+ outlinks | SEO |
| 3+ data points, each with source + year + link | SEO/GEO |
| No number, quote, customer name, or URL without a real source | Integrity |
| 1-2 citation-ready quote boxes | GEO |
| FAQ: 5-7 researched questions, 40-60-word answers | SEO |
| FAQPage JSON-LD | Schema |
| Article/BlogPosting JSON-LD (author, datePublished, dateModified, image) | Schema |
| BreadcrumbList JSON-LD | Schema |
| Person JSON-LD for author (+ reviewers) with `sameAs` | Schema |
| DefinedTerm JSON-LD for coined terms | Schema |
| Comparison: Product JSON-LD; aggregateRating only from real review data | Schema |
| How-to: HowTo JSON-LD with numbered steps | Schema |
| Glossary: DefinedTerm + DefinedTermSet JSON-LD | Schema |
| Editorial / "how we research" footer line | E-E-A-T |
| Changelog block (pillars, comparisons, evergreen guides) | E-E-A-T |
| Brand name spelled as on the rest of the site | GEO |
| Pillars: at least one first-party data point | GEO |
| Comparisons: scannable table near the top | GEO |
| Comparisons: verdict names a winner per use case with a number-based contrast | GEO |
| Cluster posts: inline link up to the parent pillar | GEO |
| Pillars: links down to every cluster post | GEO |
| Publish: URL in blog sitemap with correct lastmod | Discoverability |
| Publish: URL + summary in /llms.txt (if the site has one) | Discoverability |
| Publish: root sitemap references the blog sitemap | Discoverability |
| Publish: dateModified bumped on linking pillars/comparisons | Freshness |
| Image prompts included; images have alt text | Content |
| No banned words (`playbook.md` + gtm-context Voice) | Humanization |
| No AI-tell patterns; em dashes <= 2 per 2,500 words | Humanization |
| Sentence-length variance matches the target distribution | Humanization |
| Clear point of view; at least one non-commodity insight | Quality |
| People and companies from private conversations anonymized | Integrity |
| Title < 60 chars, meta description < 155 chars | SEO |
